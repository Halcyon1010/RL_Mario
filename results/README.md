# Results

This directory contains curated evidence for the final Mario PPO intrinsic reward experiments.

Final methods:

- PPO + NGU
- PPO + RE3
- PPO + E3B

Final 1M-step runs:

- `metrics/ppo_ngu_1m_seed1/`
- `metrics/ppo_re3_1m_seed1/`
- `metrics/ppo_e3b_1m_seed1/`

Reports:

- `reports/RUN_REPORT_ppo_ngu_re3_e3b.md`
- `reports/RUN_REPORT_transfer_1_2_1000ep.md`
- `reports/RUN_REPORT_dual_best_1_1_1_2_1000ep.md`

Boundary:

- Checkpoints are not included.
- Full remote artifacts are not included.
- Interrupted runs are not included as final evidence.
- The current evidence uses seed 1 only, so results should not be described as statistically significant.
