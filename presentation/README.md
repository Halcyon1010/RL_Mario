# Mario RL PPT v4 package

This package contains:

- `Mario_RL_PPO_intrinsic_reward_presentation_v4_method_pages.pptx`: six-slide method-focused deck.
- `animated_gifs/`: GIF clips embedded in the PPT for safer playback in PowerPoint slideshow.
- `mp4_videos/`: source MP4 videos for manual reinsertion if a host presentation strips GIF/media.
- `charts/`: validation and reward-progress charts used in the slides.
- `data/mario_reward_progress_consistency_v4.csv`: 1000-episode reward/progress consistency table.

The deck intentionally does not include a final cross-method ranking page. Each method is presented as a standalone unit.
